# 📋 Sistema de Registro de Atendimento - Ecosystems

Sistema web desenvolvido para auxiliar no registro, acompanhamento e gerenciamento de atendimentos realizados aos clientes.

O projeto centraliza informações dos clientes e mantém um histórico dos atendimentos, facilitando consultas e o acompanhamento das situações registradas.

## 🚀 Funcionalidades

- 🔐 Autenticação de usuários
- 👤 Cadastro e gerenciamento de clientes
- 📝 Registro de atendimentos
- 🔎 Pesquisa de clientes e atendimentos
- 📚 Histórico de atendimentos por cliente
- 🏷️ Classificação dos atendimentos por categoria
- 🚦 Controle de situação:
  - Pendente
  - Em andamento
  - Concluído
- 👨‍💻 Identificação do atendente responsável
- 🔠 Padronização das observações em letras maiúsculas
- 👥 Controle e aprovação de usuários
- ☁️ Sincronização dos registros com Firebase
- 📱 Interface responsiva para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas
